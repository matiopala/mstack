Would two workers retrying at once be safe?
        
That remains open. This example runs one worker at a time. It assumes each attempt can be looked up by a reference saved before submission, a closed attempt can never capture later, and a fresh second attempt succeeds immediately. To answer the concurrency question for a real service, inspect how workers claim an order and what the processor guarantees when two requests arrive together.
