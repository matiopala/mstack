decisions were explicitly labeled evaluation fixtures. The first implementation

  A separately authorized evaluator-performed local merge then reached complete.

## Boundary review and corrections

Independent review evidence is retained under
`/private/tmp/method-boundary-72zzr3ax/`, including original failing reproductions.
Review found two material issues: accepting `HEAD` as a delivery target could
complete without merging into a branch; capturing a candidate could include
pre-staged files outside its explicit path enumeration. The controller now retains
a canonical branch ref and rejects unlisted staged paths before side effects.
Regression tests cover both original failures and preservation of existing work.

Independent fix retesting is retained at
`/private/tmp/method-fixed-boundaries-vys9uggk/fix-retest-summary.json`: new HEAD
targets and delivery from the original legacy HEAD task were rejected; unlisted
staged paths were rejected with index/worktree/pending state unchanged; explicitly
enumerated paths captured successfully; normal verification, acceptance, manual
local merge, and observed delivery still reached complete. No new defect was found
within these two focused retests.

The review also noted stripped trailing whitespace in retained diffs. Diff archives
now retain exact Git bytes, independently checked against `git diff --binary`.

## Limits

These are bounded trials, not reliability estimates across projects or hosts.
Human decisions were simulated; actual product acceptance remains the user's job.
Crash checks cover known transaction boundaries and controlled actor reconciliation,
not power-loss fault injection. Browser verification did not include a screen-reader
audit or every task state. Native host tool calls rely on coordinator interruption
for limits; only controller-owned commands enforce process-group timeouts directly.
Approval provenance is recorded, not cryptographically authenticated. Delivery is
manual, with observed local branch evidence distinguished from human confirmation.
